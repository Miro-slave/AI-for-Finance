# RAG Pipeline для поиска релевантных документов

## Описание проекта

Проект реализует Retrieval-Augmented Generation (RAG) pipeline для решения задачи поиска релевантных документов по вопросам пользователей. В качестве базы знаний используется корпус текстов, собранных со страниц сайта Альфа-Банка.

Основная цель системы — для каждого пользовательского запроса находить наиболее подходящие фрагменты документов и использовать их в качестве контекста для генерации ответа.

Проект разработан в рамках хакатона "Альфа будущее".

## Архитектура решения

Pipeline состоит из нескольких этапов:

1. **Подготовка данных**

   * Загрузка корпуса документов из CSV-файла.
   * Разбиение документов на смысловые сегменты (чанки).
   * Формирование объектов документов с метаданными.

2. **Индексация**

   * Генерация эмбеддингов с помощью модели `text-embedding-3-small`.
   * Построение векторного индекса на базе FAISS для быстрого поиска.

3. **Поиск релевантного контекста**

   * Выполнение семантического поиска по векторному индексу.
   * Извлечение топ-N наиболее близких чанков.

4. **Переранжирование**

   * Дополнительная сортировка найденных документов с использованием модели `Qwen3-Reranker-4B`.
   * Отбор наиболее релевантных фрагментов для формирования итогового контекста.

5. **Генерация ответа**

   * Передача вопроса и найденного контекста в языковую модель `Gemma 3 27B IT`.
   * Формирование подробного ответа на русском языке с учетом найденной информации.

## Используемые технологии

* Python 3.10+
* LangChain
* FAISS
* OpenAI Embeddings
* Gemma 3 27B IT
* Qwen3-Reranker-4B
* Pandas
* NumPy

## Входные данные

### Корпус документов

Файл содержит тексты страниц базы знаний:

* `web_id` — идентификатор страницы;
* `url` — адрес страницы;
* `title` — заголовок страницы;
* `text` — содержимое страницы.

### Вопросы пользователей

* `q_id` — идентификатор вопроса;
* `query` — текст вопроса.

## Результат работы

На выходе формируется файл `submission.csv`, содержащий:

* идентификатор вопроса;
* текст вопроса;
* сгенерированный ответ.
